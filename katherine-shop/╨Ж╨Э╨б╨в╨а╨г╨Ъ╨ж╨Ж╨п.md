# Окремий магазин: що робити (для не програміста)

Це ПОВНИЙ окремий проєкт. Він не пов'язаний із сайтом онлайн-запрошень.

## Крок 1. Новий проєкт у Supabase
1. supabase.com → New project → назва `katherine-shop` → придумайте пароль → Create.
2. Зліва SQL Editor → New query → вставте текст нижче → Run (має бути Success):
```sql
create table orders (
  id uuid primary key default gen_random_uuid(),
  order_id text unique not null,
  items jsonb not null,
  total integer not null,
  name text, phone text, city text, np_branch text,
  status text default 'new',
  liqpay_status text,
  paid_at timestamptz,
  created_at timestamptz default now()
);
alter table orders enable row level security;
```
3. Project Settings → API. Скопіюйте два значення: «Project URL» та ключ «service_role» (секретний).

## Крок 2. Новий репозиторій на GitHub
1. github.com → зелена кнопка New → назва `katherine-shop` → Create repository.
2. На сторінці репозиторію натисніть «uploading an existing file».
3. Розпакуйте архів katherine-shop.zip на комп'ютері, відкрийте папку і перетягніть у вікно GitHub ВСЕ, що всередині (папки app, data, public, later-liqpay і файли). Натисніть Commit changes.

## Крок 3. Новий проєкт у Vercel
1. vercel.com → Add New → Project → виберіть репозиторій katherine-shop → Import.
2. Розкрийте «Environment Variables» і додайте дві змінні:
   - `NEXT_PUBLIC_SUPABASE_URL` = Project URL із кроку 1
   - `SUPABASE_SERVICE_ROLE_KEY` = ключ service_role
3. Натисніть Deploy. Через 1–2 хвилини Vercel покаже адресу сайту. Магазин на головній.

## Крок 4. Перевірка
Додайте сертифікат у кошик, оформіть замовлення. У Supabase → Table Editor → orders має з'явитись запис.
